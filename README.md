# Desk Chess

Hands-first chess for Meta Quest (WebXR / IWSDK). Place the board on your real desk with a pinch, then move pieces with hands. Hot-seat multiplayer with reacting characters. Fully usable without controllers.

Designed for seated play. Satisfying games in under 10 minutes.

## Features

- Hands-only piece movement (pinch to grab and place)
- Real desk as the board surface via passthrough + hit testing
- Hot-seat two-player mode
- Adaptive reactions from characters
- Chess rules enforced with chess.js
- Fast start, clean pause

## Run

```bash
npm install
npm run dev
```

Open in Quest Browser → Enter AR. Or test in IWER emulator.
